## 初期データ

| 項目     | 内容                                                             |
| -------- | ---------------------------------------------------------------- |
| データ   | [提供CSV](../db/seed/landit_coding_test_seed.csv) の200件        |
| 取込     | 空のDBの初回起動時に、PostgreSQLの `COPY` で一括取込             |
| 整合性   | テーブル作成・取込・インデックス作成を単一トランザクションで実行 |
| 位置情報 | `geography(Point, 4326)` とGiSTインデックス                      |
| 再起動   | 既存のデータとIDを保持。CSV変更の自動同期は行わない              |

TypeORMは既存テーブルを利用し、スキーマ変更やCSV取込は行いません。取込失敗時やデータを作り直す場合は [開発・検証ガイド](development.md#起動設定の変更とトラブル対応) を参照してください。

## 周辺検索API

```sh
curl 'http://localhost:3001/spots/nearby?latitude=35.6812&longitude=139.7671&radiusKm=1.5'
```

| 必須パラメータ | 許容値                                           |
| -------------- | ------------------------------------------------ |
| `latitude`     | −90〜90                                          |
| `longitude`    | −180〜180                                        |
| `radiusKm`     | 正の有限数値（小数可、メートルへの変換後も有限） |

半径内の全件を距離の昇順、同距離ならIDの昇順で返します。半径の境界も含みます。

| 応答         | 内容                                                                                                                               |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------------- |
| `200`        | スポットの配列。各要素は `id`・`name`・`category`・`address`・`latitude`・`longitude`・`distanceMeters` を持つ。距離はメートル単位 |
| `200` / `[]` | 該当なし                                                                                                                           |
| `400`        | 入力不正                                                                                                                           |
| `503`        | DB検索失敗（`Spot search unavailable`）                                                                                            |

入力検証の詳細は [スキーマ](../apps/api/src/spots/nearby-spots-query.schema.ts)、境界値や異常系の確認は [APIテスト](../apps/api/test/) を参照してください。
